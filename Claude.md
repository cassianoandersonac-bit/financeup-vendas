# FinanceUp — Contexto do Projeto

## Repositório
GitHub: cassianoandersonac-bit/financeup-vendas
Vercel: financeup-vendas.vercel.app

## Arquivos no repositório
- index.html — página de vendas principal
- app.html — o app FinanceUp (entregue ao comprador)
- obrigado.html — página pós-compra com links do app e bônus
- bonus-meu-banco.html — calculadora do banco pessoal (bônus)
- FinanceUp-venda.html — versão antiga (não usar)

## Produto
- Nome: FinanceUp — Controle Financeiro Pessoal
- Preço: R$ 19,99 pagamento único
- Plataforma de venda: Kiwify
- Checkout: pay.kiwify.com.br/qHNcVXk
- Público: assalariados e jovens de baixa renda

## Stack
- HTML puro + CSS + JavaScript vanilla
- Sem framework, sem dependências externas
- Funciona offline (localStorage)
- PWA configurado (installable)

## Identidade visual
- Cor primária: #0d9488 (teal)
- Cor secundária: #14b8a6
- Fonte: Plus Jakarta Sans (app) / Syne + DM Sans (páginas)
- Estilo: mobile-first, clean, dark hero

## O que NÃO mexer
- Lógica de PIN de segurança
- Sistema de onboarding/tutorial
- Funções de backup/restore
- Checkout do Kiwify
